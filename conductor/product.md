# Product Definition: Stockwellness

## 1. Vision & Core Value
Stockwellness는 요동치는 장중의 소음에서 벗어나, 하루의 장이 마감된 후(Post-Market) 자신의 투자 성과를 차분하게 복기하고 포트폴리오의 건강 상태를 점검하는 '포트폴리오 애프터 케어(After-Care)' 서비스입니다.

## 2. Target Audience
- **개인 투자자 (Retail):** 복잡한 지표보다 직관적인 포트폴리오 건강 점수를 통해 자신의 투자 상태를 파악하고 싶은 사용자.
- **가치 투자자 (Value):** 장기적인 자산 배분과 리스크 관리를 통해 안정적인 수익을 추구하는 사용자.

## 3. Key Goals
- **포트폴리오 건강 진단:** 자산 배분, 리스크, 수익률을 종합 분석하여 직관적인 '건강 점수'와 등급을 부여합니다.
- **전략 검증 (Strategy Lab):** 복잡한 코딩 없이 클릭 몇 번으로 나만의 투자 전략을 과거 데이터로 검증(Backtest)합니다.

## 4. Key Features
- **Health Diagnosis (건강 진단):** 포트폴리오의 분산도, 변동성, 배당 수익 등을 종합하여 매일의 건강 리포트를 제공합니다.
- **Strategy Lab (전략 연구소):** 거치식/적립식 전략을 시뮬레이션하고 벤치마크(KOSPI 등)와 비교 분석합니다.
- **AI Sector Insights (AI 섹터 인사이트):** 인공지능이 분석한 시장 주도 섹터와 트렌드를 실시간으로 제공하여 투자 기회를 포착하도록 돕습니다.
- **Closing Ritual (클로징 리추얼):** 장 마감 후 업데이트된 데이터를 기반으로 하루의 매매를 복기하고 내일의 전략을 세웁니다.
- **Automated Deployment (배포 자동화):** GitHub Actions를 통해 n8n 서버에 배포 웹훅을 전송하여 자동 배포 프로세스를 트리거합니다.

## 5. Design Principles (Healing UX)
- **미니멀 & 고효율 (Clean UI):** 군더더기 없는 디자인과 효율적인 정보 전달을 최우선으로 하여 투자 피로도를 낮춥니다.
- **Data Clarity:** 중요한 지표는 포인트 컬러를 사용하여 직관적으로 전달하며, 일관된 데이터 포맷을 유지합니다.
