# Specification: 주식 차트 및 관심 종목 기능 오류 수정

## 1. 개요
이 트랙은 주식 상세 화면의 주봉(1W) 차트 데이터 정합성 오류와 관심 종목(Watchlist) 기능의 비정상적인 동작을 수정합니다.

## 2. 기능 요구사항
### 2.1. 주식 차트 수정
- **주봉(1W) 차트 데이터 정합성:** 주봉 뷰에서 발생하는 데이터 렌더링 오류를 조사하고 수정합니다. API에서 제공하는 주봉 기록 데이터가 차트에 정확하게 반영되도록 보장합니다.
- **데이터 검증:** 차트 데이터에 대한 검증 로직을 구현하거나 확인하여 잘못되거나 누락된 데이터 포인트가 렌더링되지 않도록 합니다.

### 2.2. 관심 종목(Watchlist) 기능 고도화
- **하트 아이콘 상태:** 주식의 관심 종목 등록 여부를 하트 아이콘이 정확하게 반영하도록 합니다. (빨간색 = 관심 종목 등록됨, 테두리만 있는 하트 = 등록되지 않음)
- **추가/제거 기능 구현:** `watchlistApi`를 사용하여 '관심 종목 추가' 및 '관심 종목 제거' 기능을 구현하거나 수정합니다.
- **상태 동기화:** 관심 종목 추가 또는 제거 후 즉시 UI가 업데이트되도록 보장합니다.

## 3. 비기능 요구사항
- **성능:** 차트 렌더링이 부드럽게 유지되어야 합니다.
- **신뢰성:** 관심 종목 상태는 백엔드 데이터와 일관성을 유지해야 합니다.

## 4. 인수 조건
- [ ] 주봉 차트가 오류 없이 정확한 데이터를 표시합니다.
- [ ] 관심 종목에 등록된 주식의 경우 하트 아이콘이 빨간색으로 표시됩니다.
- [ ] 하트 아이콘을 클릭하면 관심 종목에 추가되거나 제거됩니다.
- [ ] 관심 종목 작업 성공 후 UI 피드백(토스트 또는 아이콘 변경)이 발생합니다.
- [ ] 모든 관련 단위/E2E 테스트를 통과합니다.

## 5. 범위 제외 (Out of Scope)
- 새로운 차트 유형 추가 (예: 캔들스틱 차트 등 기존에 없는 유형)
- 차트용 고급 기술 지표 추가
