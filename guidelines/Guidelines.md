## 버튼 (Button)
버튼 컴포넌트는 디자인 시스템의 핵심적인 인터랙티브 요소로, 액션을 트리거하거나 사용자를 애플리케이션 내에서 안내하도록 설계되었습니다. 사용자 경험을 향상시키기 위해 시각적 피드백과 명확한 어포던스(affordance)를 제공합니다.

### 사용법
버튼은 폼 제출, 선택 확인 또는 프로세스 시작과 같이 사용자가 수행해야 하는 중요한 액션에 사용해야 합니다. 인터랙티브함을 전달해야 하며 명확하고 액션 중심적인 라벨을 가져야 합니다.

### 변형 (Variants)
* 기본 버튼 (Primary Button)
  * 용도: 섹션이나 페이지의 주요 액션에 사용
  * 시각적 스타일: 굵게 표시, 브랜드 기본 색상으로 채워짐
  * 사용법: 사용자를 가장 중요한 액션으로 유도하기 위해 섹션당 하나의 기본 버튼 사용
* 보조 버튼 (Secondary Button)
  * 용도: 대안 또는 지원 액션에 사용
  * 시각적 스타일: 기본 색상 테두리, 투명한 배경
  * 사용법: 덜 중요한 액션을 위해 기본 버튼 옆에 배치 가능
* 삼차 버튼 (Tertiary Button)
  * 용도: 가장 중요도가 낮은 액션에 사용
  * 시각적 스타일: 테두리 없는 텍스트 전용, 기본 색상 사용
  * 사용법: 사용 가능해야 하지만 강조되지 않아야 하는 액션에 사용
